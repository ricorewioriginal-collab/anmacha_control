# Project Decisions — Consolidated

- AnMaCha bleibt eigenständig.
- AirDeck wird eigenständig.
- AirDeck kann AnMaCha optional integrieren, benötigt es aber nicht.
- Bestehende Online-Automation bleibt unabhängig.
- Eigene Live/Relay-Automation wird zuerst ausgebaut.
- Source Priority: positive Integer, kleinere Zahl = höhere Priorität.
- AirDeck: Windows + Android + Self-Hosted.
- Professionelle DSP/Encoder/Monitoring + 4 Decks/Cardwall.
- AI local/free-first where practical, externe Provider optional, AI nie Single Point of Failure.
- Cloud user-configurable, Local-First, Sync API/Event Architektur.
- Developer API: REST/WebSocket/Webhooks, Scopes/RBAC, Plugins/Connectors.
- AirMotion als eigene Funktion, keine proprietären Fremdimplementierungen kopieren.
