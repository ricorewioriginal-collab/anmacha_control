# AirDeck Standalone Rules

1. AirDeck läuft ohne AnMaCha.
2. Keine Kernfunktion benötigt zwingend einen AnMaCha-Server.
3. Eigene AI Provider / API Keys.
4. Eigene lokale DB und Medienverwaltung.
5. Eigene Server-/Cloud-Konfiguration.
6. AnMaCha = optionaler Connector.
7. laut.fm = optionaler Adapter.
8. Icecast/SHOUTcast/Relay = Broadcast-Adapter.
9. Offline-first.
10. Source Priority = wiederverwendbare Domain-Komponente.
