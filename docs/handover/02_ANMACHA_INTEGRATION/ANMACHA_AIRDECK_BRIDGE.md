# AnMaCha ↔ AirDeck — optionale Integration

AirDeck bleibt vollständig unabhängig.

AnMaCha kann später:
- AirDeck-Instanzen erkennen
- Senderstatus anzeigen
- Now Playing anzeigen
- Sendeplan anzeigen
- ausgewählte Steuerungen anbieten
- AirDeck Design System optisch übernehmen

Nicht zulässig:
- AirDeck benötigt AnMaCha zum Starten
- AirDeck Core auf AnMaCha Server auslagern
- AirDeck AI von AnMaCha AI abhängig machen
- fremde Senderdaten ohne Berechtigung zentralisieren

Die Integration ist optional und erst nach Stabilisierung von AirDeck zu priorisieren.
