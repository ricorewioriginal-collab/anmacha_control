# Developer API Scope Matrix

| Scope | Zugriff |
|---|---|
| now_playing:read | read |
| schedule:read | read |
| stream:read | read |
| branding:read | read |
| queue:read | read |
| queue:write | write |
| cardwall:read | read |
| cardwall:trigger | action |
| sources:read | read |
| sources:write | write |
| automation:read | read |
| automation:write | write |
| credentials:read | **nie für Drittanbieter-Plugins** |

Jeder Scope an RBAC und Senderberechtigungen koppeln.
