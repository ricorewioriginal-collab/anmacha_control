# Live/Relay UI Rules

- dark broadcast UI
- kompakte Panels
- cyan/violet accents
- klare grüne On-Air-States
- vier Decks
- Cardwall in Standardansicht
- Playlist + Queue
- Source/priority panel
- encoder + DSP
- Now Playing / Next
- meters

Der aktive Source muss eindeutig sichtbar sein, z. B. `LIVE • PRIORITY 1`, plus connection state, source type, sender, priority, takeover control und fallback status.

Die UI darf Priority 1 niemals optisch als schlechter als Priority 10 darstellen.
