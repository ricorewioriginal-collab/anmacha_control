# AirDeck Design System

## Stil
Professionelles Broadcast-Studio: dunkel, dicht, klar, cyan/blau als technische Akzente, Statusfarben sparsam, hohe Informationsdichte.

## Standard Windows View
Header → Sender/On Air → 4 Decks → Cardwall → Playlist/Queue/Live Voice → Now Playing/Next → DSP/LUFS/Encoder.

## Mobile
Home → Now Playing → Decks → Cardwall → Playlist → Sendeplan → Events → AI/Automation → Stream.

## Sender Theme
Logo, Slogan, Primärfarbe, Akzentfarbe, Panel Theme, Sender Assets.

## AnMaCha später
Das Design System darf nach Stabilisierung als optische Sprache in der bestehenden AnMaCha Automation eingesetzt werden. Keine technische Kopplung erzwingen.
