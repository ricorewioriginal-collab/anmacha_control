# AirDeck WordPress Plugin

Eigenständiges WordPress-Plugin als Alternative zu AirDeck-internen Widgets.

## Datenquelle
Vom Betreiber konfigurierbare AirDeck API/Cloud.

## Widgets
- On Air
- Now Playing
- Next Track
- Sendeplan
- Stream Status
- Senderbranding
- Show/Moderator
- Events
- weitere AirDeck Widgets

## Anforderungen
- kein AnMaCha-Zwang
- sichere API-Konfiguration
- Cache
- Fehler-/Offline-Zustand
- responsive
- Senderbranding
- minimale externe Abhängigkeiten
